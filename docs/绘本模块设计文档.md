# AI 启蒙绘本模块 · 设计文档

> 面向小学 1～3 年级（6～9 岁）的多模态动画绘本。
> 本文件对应要求里的「输出内容」：**分页脚本表 / 画面描述 / 角色台词 / 互动设计 / 音效与 TTS 提示 / 前端组件结构 / 与主对话智能体的接口设计**。

---

## 一、核心定位：不是「配图知识卡」

做的是**动画绘本**，不是一页图配一句话再加一道选择题。

| 做法 | 说明 |
| --- | --- |
| **先让孩子喜欢角色** | 三个固定主角各有口头禅、会犯错、会害羞、会开心。每本里角色都要成长一点点 |
| **再跟着角色经历一件事** | 每本 8～12 页，走完整的情绪曲线：好奇 → 遇到问题 → 着急 → 想办法 → 发现线索 → 再试 → 小挫折 → 成功 → 邀请互动 → 奖励与告别 |
| **知识由角色说出** | 知识点**从不单独成页讲**，全部藏在角色的台词里。例：小AI 说「我看过好多好多猫的图片，所以一看到猫，我就知道它是猫啦！」 |
| **画风固定、角色一致** | 每本固定一种画风（水彩底 + 圆润卡通角色），角色形象跨页完全一致 |
| **每页一个视觉焦点** | 主角占画面高度 40%～60%，背景不超过三层，不堆信息 |

## 二、角色设定

| 角色 | 外形 | 性格 | 口头禅 | 会犯的错 |
| --- | --- | --- | --- | --- |
| 🤖 **小AI** | 圆滚滚、会发光、天线顶一颗小灯，头占身高一半 | 热心、有点笨笨的、爱逞强 | 「让我试试看！」 | 端不稳水杯、说话会乱、会认错 |
| 👧 **点点** | 6 岁，橙色小裙子，两个丸子头，笑成月牙眼 | 好奇、温柔、有耐心 | 「为什么呀？」 | 也会着急、也会想不通 |
| 🐶 **豆豆** | 机器狗，脸上有一块小屏幕当眼睛 | 老实、努力、常常理解错 | 「汪汪？我猜的对吗？」 | 把老虎认成猫、把「小猫」听成「小毛」 |

表情系统共 11 种：开心 / 大笑 / 星星眼 / 惊奇 / 困惑（歪头加问号）/ 着急（汗滴加皱眉）/ 害羞 / 难过 / 眨眼 / 平静 / 委屈。眼睛用 `<g class="pb-blink">` 包起来，浏览器每 4 秒眨一次。

## 四、AI 知识的低龄化表达（禁用抽象术语）

**内容校验会强制拦截**以下词，出现即报错、无法提交：

| 抽象术语 | 必须换成 |
| --- | --- |
| 机器学习 | 「AI 看很多很多图片，就学会了」 |
| 深度学习 | 「AI 一层一层地看，看得越来越细」 |
| 神经网络 | 「AI 身体里有很多很多小开关」 |
| 算法 | 「AI 做事的小步骤」 |
| 训练数据 / 数据集 | 「AI 的学习卡片」 |
| 语音识别 | 「一双会听声音的耳朵」 |
| 图像识别 | 「一双会看东西的眼睛」 |
| 标注 | 「告诉它哪个对」 |
| 人工智能 | 「一个很会帮忙的聪明朋友」 |
| 模型 / 参数 / 权重 / 梯度 | 不出现，换成看得见的动作 |

受监控词表共 **12 条正则**，覆盖正文、角色台词、小问题、伴读回答四处。

## 六、互动设计（像玩，不像考试）

| 类型 | 玩法 | 技术实现 | 年级 |
| --- | --- | --- | --- |
| **点一点** | 点小AI 的头，它会眨眼 | 按钮 + 脉冲光环 | 1～3 |
| **拖一拖** | 把苹果拖给豆豆看它认不认得 | HTML5 拖放；**触摸设备点两下也能完成** | 1～3 |
| **吹一吹** | 对着麦克风吹气，风车转动 | Web Audio `AnalyserNode` 取 RMS，超过基线 45% 判定成功 | 1～3 |
| **拍一拍** | 拍手让声控灯亮起来 | 同上，RMS 突增 12% 判定 | 1～3 |
| **选一选** | 两个选项，选错角色歪头说「再想想看？」 | 不锁死、不变红，可以一直试 | 2～3 |
| **找一找** | 在画面里找出 3 个会看/会听的东西 | 绝对定位热区 | 2～3 |
| **说一句** | 对着麦克风说「小AI，你好」 | Web Speech API；不支持时自动切成打字 | 3 |

**麦克风打不开怎么办**：每一项都准备了「点一下也算」的兜底按钮，绝不让小朋友卡住。

**反馈原则（写进代码）**：
- 答对 → 星星飞出 + 角色欢呼 + 语音「太棒了！」+ 音效 `cheer`
- 答错 → 角色歪头 + 「没关系，我们再来一次」+ 音效 `soft`（柔和单音）
- **不扣分、不红灯、不出现「错误」字样**（全项目搜索确认）

## 七、音效与 TTS

**音效全部用 Web Audio 现场合成，零音频素材**（所以断网也能用）：

| 名称 | 合成方式 | 用在哪 |
| --- | --- | --- |
| `pop` | 三角波 520→880Hz，0.13s | 点一下、拖放成功 |
| `ding` | 正弦 1180 + 1770Hz | 找到线索 |
| `chime` | 880/1174/1568Hz 三音上行 | 想通了、问答成功 |
| `clap` | 带通噪声两下 | 拍手 |
| `whoosh` | 带通噪声 0.42s | 吹气、擦地 |
| `cheer` | 784/988/1174/1568Hz 四音上行 | 答对欢呼 |
| `giggle` | 880/1100/880Hz 短音 | 角色笑 |
| `warm` / `heart` | 523/659Hz、659/880Hz 长音 | 温暖收尾 |
| `soft` | 392Hz 柔和单音 | **答错时的温柔提示** |
| `page` | 高频噪声 | 翻页 |
| `star` | 1318/1568/2093Hz | 收集星星 |

**TTS 提示**：
- 语速按年级给：一年级 **0.82**（很慢）、二年级 0.92、三年级 1.0，界面上还能再调四档
- 音调偏高（1.25 / 1.18 / 1.10），更接近儿童故事朗读
- 优先选中文女声/童声（匹配 `Xiaoxiao|Huihui|Yaoyao|Tingting`）
- **逐字高亮**：朗读时当前字符会加 `.is-reading` 高亮背景，读完自动清除
- 读一页时会把**旁白和角色台词连起来读**，孩子才知道角色说了什么
- 点任意一个汉字，能单独听这个字的读音

## 八、自适应与个性化

**按年级分档**（写在 `pb-engine.js` 的 `BANDS` 里，被校验强制执行）：

| 年级 | 目标页数 | 每页句数 | 单句字数 | 可用互动 | 小问题间隔 | 语速 |
| --- | --- | --- | --- | --- | --- | --- |
| 一年级 | 8 | ≤ 1 句 | ≤ 13 字 | 点、拖、吹、拍 | 每 3 页 | 0.82 |
| 二年级 | 10 | ≤ 2 句 | ≤ 15 字 | 加 选一选、找一找 | 每 3 页 | 0.92 |
| 三年级 | 12 | ≤ 3 句 | ≤ 20 字 | 加 说一句、排一排 | 每 4 页 | 1.00 |

故事本身不足 12 页时按比例取整，保证三个年级读到的页数**确实不一样**。

**按表现调整**（`pb-engine.adapt()`）：

| 触发条件 | 调整 | 对孩子说的话 |
| --- | --- | --- |
| 连续答错 ≥ 2 次 | 下一本页数 −2，只保留最简单互动 | 「没关系，我们可以读一本简单一点的。你已经很努力啦！」 |
| 最近 4 次正确率 ≥ 85% | 下一本页数 +2，多一个新玩法 | 「你太厉害了！下一本我们多读两页，好不好？」 |
| 其他 | 按当前水平 | 「我们继续读下去吧！」 |

**按兴趣选书**：每本书带 `interests` 标签（动物 / 太空 / 音乐 / 故事 / 生活 / 朋友），绘本馆会优先推还没读过、且符合兴趣的那一本。
**已学不重复**：`pb.recommend()` 会排除 `progress.books` 里已经读完的。

## 九、前端组件结构

零依赖，全部是经典脚本（IIFE + `var`），可以直接 iframe 嵌入。

```
public/js/picturebook.js          （约 1220 行）
├─ S            状态：年级 / 当前书 / 页 / 星星 / 作答记录
├─ SFX          Web Audio 合成音效（11 种）
├─ Mic          麦克风电平检测（吹一吹 / 拍一拍共用）
├─ ASR          语音指令（继续讲 / 换一本 / 读给我听）
├─ TTS          speechSynthesis + 逐字高亮 + 语速音调控制
├─ renderLibrary()      绘本馆：推荐条 + 8 本书架 + 贴纸 + 徽章 + 成长树
├─ openBook(id)         取书并按年级生成
├─ renderReader(turn)   阅读器：顶栏 + 插图 + 拼音大字 + 台词条 + 互动卡 + 控制条
│   ├─ buildText()      逐字可点的大字
│   └─ buildAction()    七种互动的分发器
│       ├─ tap / drag / blow / clap / choose / find / say
├─ showQuestion()       每 2～4 页插入的小问题
├─ startExercises()     读完后的三个小游戏（选一选 / 连一连 / 排一排 / 说一说）
├─ finishBook()         结算：星星 + 贴纸 + 徽章 + 成长树 + 下一本建议
└─ buildAsk()           右下角「问小AI」，回答可变成一页绘本
```

**服务端**：
```
server/lib/pb-cast.js     角色系统（3 个主角 × 11 种表情）+ 8 种情绪调色板 + 场景零件
server/lib/pb-scenes.js   74 个页面的编排表（背景层 / 角色摆位 / 道具 / 点缀 / 气泡）
server/lib/pb-engine.js   分档、取页、拼音切分、小问题、自适应、奖励结算、内容校验
server/lib/pinyin.js      407 音节表 + 数字声调转符号
server/lib/pb-art.js      绘图指令 → SVG
server/content/pb-stories-a~d.js + pb-index.js   8 本故事脚本
public/css/picturebook.css                        阅读器样式（含 7 种互动）
```

**画面动效**（CSS，服务端只画静态一帧）：
`.pb-blink` 眨眼 · `.pb-glow` 光晕浮动 · `.pb-twinkle` 星星闪 · `.pb-mote` 光点呼吸 · `.pb-tail` 摇尾巴 · `.pb-turn-next/prev` 翻页翻转 · `prefers-reduced-motion` 下全部关闭。

## 十、与主对话智能体的接口设计

### 10.1 数据共享

绘本进度写在**同一个学生档案**里（`data/students/<id>.json` 的 `pb` 字段），与对话记录、错题本、徽章共用一份数据，无需额外同步：

```json
{
  "pb": {
    "books": { "wake": { "stars": 9, "done": true, "correct": 6, "total": 8, "reads": 2 } },
    "stars": 14,
    "stickers": ["🦄", "🌈"],
    "badges": ["pb-first", "pb-kind"],
    "recent": [true, false, true, true, false]
  }
}
```

`recent` 是最近 12 次作答的正误，`adapt()` 靠它决定下一本的长度与难度。

### 10.2 HTTP 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/pb/library?grade=&interest=` | 书目 + 进度 + 成长树 + 推荐 + 自适应建议 |
| GET | `/api/pb/book?id=&grade=&pages=&level=&pinyin=` | 一本可读的绘本（分档文字 + 拼音 + 插图 + 台词 + 互动 + 小问题） |
| POST | `/api/pb/ask` | 伴读问答；返回回答 + 可变成一页绘本的图文 |
| POST | `/api/pb/answer` | 互动/小问题/游戏作答（答错自动进错题本） |
| POST | `/api/pb/finish` | 结算星星、贴纸、徽章、成长树、下一本建议 |
| POST | `/api/pb/chat` | 绘本内直接向主教学引擎提问（复用 `tutor.answer`，按学生实际年级） |

### 10.3 主智能体如何唤醒绘本

低龄学生说「我想看绘本」「讲个故事」，`nlu.detectIntent` 识别为 `story`：

```
学生：我想看绘本
→ 意图 story，年级 ≤ 3
→ 回答：「好呀！我们读绘本。绘本里有大图、有大字，还会读给你听。」
→ 动作：打开 AI 绘本馆 → /book?grade=2
        直接读这本   → /book/read?id=wake&grade=2
```

知识点页与对话里的「读一本绘本」按钮，在**低学段**也会指向 `/book`。

### 10.4 多网页集成

```html
<!-- ① 独立整页 -->
/book?grade=2
/book/read?id=ear&grade=2&auto=1

<!-- ② iframe 嵌入：自动去掉站点导航与页脚 -->
<iframe src="/book/read?id=wake&embed=1&auto=1" style="width:100%;height:660px;border:0"></iframe>

<!-- ③ 宿主页面远程控制 -->
<script>
  var f = document.querySelector('iframe');
  f.contentWindow.postMessage({ target: 'aiq-picturebook', action: 'open',  id: 'eye' }, '*');
  f.contentWindow.postMessage({ target: 'aiq-picturebook', action: 'grade', grade: 3 }, '*');
  f.contentWindow.postMessage({ target: 'aiq-picturebook', action: 'voice', on: true }, '*');
  f.contentWindow.postMessage({ target: 'aiq-picturebook', action: 'next' }, '*');
</script>
```

URL 参数：`grade` 年级 · `id` 书目 · `auto` 自动朗读 · `embed` 嵌入模式 · `pages` 覆盖页数 · `level` 难度。

反向通知：绘本通过 `postMessage` 与 `aiq:pb` 事件广播
`libraryReady / bookOpen / question / exercise / finish / ask`，宿主可据此做外层导航或埋点。

## 十一、安全与稳定

| 要求 | 实现 |
| --- | --- |
| 无外部链接 | 全项目零外链、零 CDN、零广告、零社交功能 |
| 内容预审 | 74 页文案全部预先写定，**没有用户生成内容直接展示** |
| 术语过滤 | 12 条禁用词正则，正文/台词/问题/伴读回答四处全查 |
| 错误提示友好 | 任何接口失败都给中文提示 + 「再试一次」，不抛栈、不白屏 |
| 断网可读 | 零依赖 + 服务端渲染，整个模块在无网络的机房也能完整使用 |
| 麦克风可控 | 只在孩子点击后才申请；页面失焦自动停止；不授权也有兜底按钮 |
| 动效克制 | 尊重系统的「减少动态效果」设置，全部 CSS 动画可关闭 |

## 十二、内容校验（自动化，任何一条不过就不能提交）

`pb-engine.validate()` 会检查 **8 本 × 74 页 × 3 档文字**，逐条验证：

| 检查项 | 规则 |
| --- | --- |
