# AI 绘本馆 · 前端架构与接口设计

> 面向小学 1–3 年级（6–9 岁）的沉浸式 AI 启蒙绘本馆。
> 独立路由 **`/ai-picture-book`**，从「创作工坊」里彻底剥离，不再使用「左侧列表 + 右侧预览」的控制台布局。

---

## 〇、创作工坊里的「AI 绘本」标签页

创作工坊（`/studio`）保留顶部「🎬 原理动画 | 📖 AI 绘本」切换，但两个标签页是**完全独立的两块区域**：

| 标签 | 左侧 | 右侧 |
| --- | --- | --- |
| 🎬 原理动画 | 知识点选择（卷积、梯度下降等） | 动画舞台 |
| 📖 AI 绘本 | 主题胶囊 + 一键生成 + 绘本卡片流 | 沉浸式预览（大图 + 拼音 + 朗读 + 编辑工具条 + 翻页 + 问小AI） |

**切到「AI 绘本」时，`#studio-region-anim` 整体 `hidden`** —— 知识点列表与动画舞台一起收起，绝不会残留在页面上。
反过来切到「原理动画」，`#studio-region-book` 也整体收起。实测确认：

```
AI 绘本标签默认展开: true
动画区默认收起: true
知识点列表可见: false      ← 关键：算法列表彻底消失
主题胶囊: 6    绘本卡片: 8
预览已自动打开: true    编辑工具条: 4 个    底部控件: 4 个
切回动画后知识点可见: true    切回动画后绘本区收起: true
```

### 右侧编辑工具条

| 按钮 | 作用 |
| --- | --- |
| 🎨 重新生图 | 给这一页做造型微调（可见的即时反馈） |
| ✏️ 修改台词 | 弹输入框改这一页的台词（≤24 字） |
| 🔊 添加配音 | 用 TTS 现场配这一页的音 |
| 👆 插入互动 | 一键给这一页加/去掉一个「点一点」互动 |

预览底部还会显示这一页属于**黄金八步的第几步**以及因果触发点，方便老师讲解。

### 一键生成绘本

输入「生成一本适合 1 年级的 AI 认猫绘本」，会走一条完整的生成链：

```
自然语言 → 硬核说法优先匹配（过拟合 → 犯错啦）→ 主题关键词匹配
        → 同主题内按 prompt 稳定散列选书（不同说法挑到不同的书）
        → 展开成完整分页脚本（页面 + 画面 Prompt + 台词 + 互动 + 因果链 + 八步位置）
        → 大模型润色一句开场白（未配置自动跳过）
```

实测映射：

| 输入 | 主题 | 结果 |
| --- | --- | --- |
| 生成一本适合1年级的AI认猫绘本 | 认猫猫 | 《豆豆的眼睛》 |
| 讲一个机器怎么听懂人话的故事 | 听声音 | 《小AI 学说话》 |
| 关于过拟合和死记硬背 | 犯错啦 | 《小AI 也会错》 |
| 小AI为什么认错人 | 犯错啦 | 《谁教小AI 的呀》 |

## 三、接口定义

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/ai-picture-book?grade=1&theme=see` | 绘本馆页面（独立路由） |
| GET | `/ai-picture-book/read?id=eye&grade=1&auto=1&embed=1` | 全屏沉浸式阅读器 |
| GET | `/api/books?grade=1&theme=AI能看` | **低龄绘本列表**（支持主题 id / 主题名 / 认知点三种写法） |
| POST | `/api/books/generate` | **一键生成绘本**：传主题与年级，返回完整分页脚本 |
| GET | `/api/workbooks` | 旧口径的「实践小本子」清单（原 `/api/books` 挪到这里） |
| GET | `/api/book?id=eye&grade=1` | 一本可读的绘本（分档文字 + 拼音 + 插图 + 台词 + 互动） |
| GET | `/api/pb/library?grade=1&interest=动物` | 绘本馆数据（书目 + 进度 + 成长树 + 推荐 + 自适应建议） |
| GET | `/api/pb/book?id=eye&grade=1&level=easy` | 同上（绘本引擎口径） |
| POST | `/api/agent/ask` | **对话智能体入口**：低龄化回答 + 可变成新绘本页的图文 |
| POST | `/api/pb/ask` | 伴读问答（绘本内） |
| POST | `/api/pb/answer` | 互动 / 小问题 / 游戏作答（答错自动进错题本） |
| POST | `/api/pb/finish` | 结算星星、贴纸、徽章、成长树、下一本建议 |
| GET | `/api/pb/standard` | 画面与故事标准（全局前缀 + 黄金八步 + 角色人设 + 逐页红线自查） |
| GET | `/api/pb/storyboard?id=eye&grade=2` | 逐页分镜（五层结构 + 因果触发点 + 生图提示词） |

## 四、自适应逻辑伪代码

```text
function buildBook(bookId, user):
    grade = clamp(user.grade, 1, 3)
    band  = BANDS[grade]                       # 1 年级 8 页 / 2 年级 10 页 / 3 年级 12 页

    # ① 按年级分档：页数、每页句数、单句字数、可用互动、语速
    pages = pickPages(book, band.pageCount)     # 保持黄金八步不漏
    lines = min(len(page.text), band.maxLines)
    chars = band.maxChars
    actions = INTERACTIONS where level <= grade

    # ② 按最近的作答记录微调（recent 是最近 12 次正误）
    adapt = adaptLevel(user.progress.recent)
    if adapt == "easy":                         # 连续答错 ≥ 2 次
        pages = pages - 2
        actions = actions ∩ {tap, drag, blow, clap}     # 只留最简单的
        encouragement = "没关系，我们可以读一本简单一点的。你已经很努力啦！"
    elif adapt == "hard":                       # 最近 4 次正确率 ≥ 85%
        pages = pages + 2
        actions = actions ∪ {say, order}                 # 加一个新玩法
        encouragement = "你太厉害了！下一本我们多读两页，好不好？"
    else:
        encouragement = "我们继续读下去吧！"

    # ③ 按兴趣与已读记录选书
    candidates = BOOKS where book.id not in user.progress.books        # 已读不重复
    if user.interests: candidates = candidates ∩ themeMatches(interests) or candidates
    recommend = candidates[0]

    # ④ 朗读参数跟着年级走
    tts = { rate: band.ttsRate, pitch: band.ttsPitch }   # 1 年级 0.82 / 1.25
    return { pages, tts, actions, adapt, encouragement, recommend }

function onAnswer(page, correct):
    record(page.interaction.type, correct)      # 写进 recent
    if correct:
        stars += 1;  play("cheer");  say("太棒了！")
    else:
        # 不扣分、不红灯、不出现「错误」字样
        play("soft");  character.tiltHead();  say("没关系，我们再来一次")
```

## 六、无障碍与容错

- 每张卡片都有 `aria-label`（书名 + 年龄 + 已读状态）
- 主题胶囊是原生 `<button>`，键盘可达
- 进度条带 `role="progressbar"` 与 `aria-valuenow`
- 卡片支持 `:focus-visible` 高亮
- 麦克风只在孩子点击后才申请，页面失焦自动停止；**每一项都有「点一下也算」的兜底按钮**
- 尊重系统的「减少动态效果」设置，全部 CSS 动画可关闭
- 任何接口失败都给中文提示 + 「再试一次」，不抛栈、不白屏
