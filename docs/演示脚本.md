# 现场演示脚本（5 分钟精简版 / 10 分钟完整版）

> 演示前：`node server/server.js`，Chrome 打开 `http://127.0.0.1:8090`。
> 建议先到「学情看板 → 重新开始」清空数据，让第一次演示从干净状态开始。

---

## 一、5 分钟精简版

| 时间 | 操作 | 要讲的话 |
| --- | --- | --- |
| 0:00–0:30 | 打开首页，先**不要点任何东西**，让评委看首屏 | "这是多页面站点，不是单页应用。每个知识点都有独立网址，老师可以直接把链接发到班级群。" |
| 0:30–1:10 | 右上角设置 → 把名字填成"小启"、年级选 **1 年级** → 保存 | "产品第一件事不是聊天，而是建立学生画像。年级决定了后面每一句话怎么讲。" |
| 1:10–2:00 | 进「AI 课堂」，问：**什么是机器学习** | 让评委看三点：① 回答很短、全是生活比喻；② 结尾有一个引导思考的问题；③ 下面给了"举个例子 / 更简单一点 / 出题练一练 / 读绘本 / 看动画"的按钮 |
| 2:00–2:40 | **点顶部年级下拉 → 改成 11 年级 → 再问同样的问题** | "同一个知识库、同一个问题，回答长度从 90 字变成 300 多字，出现了'经验风险''泛化''正则化'，追问也从'你来猜猜看'变成'边界条件是什么'。这就是赛题要求的年龄自适应。" |
| 2:40–3:10 | 继续说 **听不懂** | "它会自动降一个学段重讲，而不是重复一遍。这是教学法写进代码的效果。" |
| 3:10–3:50 | 切到「创作工坊」→ 播一个动画 → 切「AI 绘本」→ 生成一本 | 动画是**可交互**的（拖分界线，准确率实时变化）；绘本文字按年级改写、插图由代码实时绘制，可朗读、可导出。 |
| 3:50–4:30 | 切到「编程实践」→ 走迷宫 → 右侧看积木翻译成 Python → 切 Python 实验室跑"循环画图" | "图形化降低门槛，代码对照帮助过渡到文本编程。这个 Python 解释器是我们自己写的，带死循环保护和中文报错。" |
| 4:30–5:00 | 切到「练习中心」→ 知识闯关答一题 → 切「学情看板」看报告 | "答错立刻解析并进错题本；所有学习行为落库，一键导出学习报告给家长或老师。" |

**收尾一句话**：整套系统零依赖、可离线，一个 U 盘拷到机房就能用；需要更自然的表达时，
在「设置」里填任意 OpenAI 兼容的 API Key 即可升级，接口异常会自动降级回本地引擎，课堂不中断。

## 二、10 分钟完整版（在精简版基础上补 4 个环节）

### 加分 1：四学段讲法对照（约 1.5 分钟）
进「课程地图」→ 搜索"过拟合" → 点开卡片。
弹窗里**并排展示四个学段**对同一知识点的情境导入、讲解、例子、活动，当前学段高亮。
再往下是术语卡、常见误区、配套练习（可当场作答）。
> 这句话很重要："内容不是同一段文字的压缩版，而是四份独立编写的教学稿。"

### 加分 2：脚手架递进（约 1 分钟）
在初中/高中状态下问"什么是神经网络"，然后连续说 **再深入讲讲**、**还有吗**。
每问一次，讲解层级从"打个比方"推进到"举个例子 → 拆成步骤 → 讲讲原理 → 来个挑战"，
内容完全不重复。
> "反复追问不会原地打转，这是把教学法做进架构的直接证据。"

### 加分 3：跨学科检索能力（约 1 分钟）
连着问三个口语化问题：**换脸视频能信吗** / **AI 会不会抢我的工作** / **程序报错怎么办**。
系统分别命中「AI 安全与负责任使用」「AI 与未来职业」「调试：程序出错怎么办」。
> "学生不会按课程目录提问，所以我们建了同义表达表，把口语映射到知识点。"

### 加分 4：大模型接入与降级（约 1.5 分钟）
「设置」→ 选 DeepSeek 或火山方舟 → 填 API Key → 点「保存并测试连接」→ 显示"连接成功（xxx ms）"。
回对话页再问一个问题，此时回答由真实大模型生成；随后可把 Key 改成错的再问一次，
界面提示"已回退本地引擎"，功能不中断。
> "我们把学段约束和课程知识片段一并注入系统提示词，所以模型不会把一年级讲成研究生课。"

### 加分 5：低年级绘本（约 2 分钟）—— 建议排在第二或第三位演示

先在「设置」里把年级改成 **1 年级**，然后点导航栏的 **「AI 绘本」**。

**第一眼要传达的**：这不是"很多字的电子书"，是给 6～9 岁做的阅读器。

1. 绘本馆：5 本，每本对应一个必须建立的 AI 认知（AI 是什么 / 能做什么 / 怎么听懂话 / 怎么学会的 / 我和 AI 的关系）。
2. 点开《小启学认猫》→ 让他们看三件事：
   - **大图 + 两个短句 + 每句上方带声调拼音**；
   - 点任意一个汉字，那个字会高亮并**单独读出来**；
   - 右下角常驻 💬「问小启」，随时能问问题。
3. 点「🔊 读给我听」→ 整页朗读；点「⏱」可以调语速（一年级默认更慢）。
4. 一路点「下一页」→ **中途跳出小问题**，选一个马上给反馈；答错也不批评，只是引导再读一遍。
5. 读到最后一页 → 点绿色的「🎉 读完了，去玩小游戏」→ 做连一连/排一排 → **结算页拿到星星、贴纸与成长树叶子**。
6. 回到绘本馆看**成长树多了一片叶子**，贴纸墙上多了一张贴纸。
7. 最后点 💬 → 问「小启会难过吗？」→ 回答下面有「📖 变成一页绘本给我看」→ **回答现场变成一页带插图的绘本**。

**要讲的两句话**：
> "同一个知识点，一年级听到的是'小启刚做好的时候什么都不会'，三年级会变成完整的两句因果句。
> 每页几句、每句几个字、练习是什么类型，都是写死在代码里并被自动校验的——超一个字内容都提交不了。"

> "它也能被任何页面嵌进去：`/book/read?id=day&embed=1`，不带导航和页脚，
> 宿主页面还能用 postMessage 远程控制它翻页、换年级、开关朗读。"

### 加分 6（可选）：现场写代码（约 1.5 分钟）
「编程实践 → Python 实验室」→ 把示例改成现场想的小程序（例如画 8 个同心圆）→ Ctrl+Enter 运行。
可以**故意写错**（例如把 `range(8)` 写成 `range()`），展示中文报错与行号：
> "报错信息本身就是教学内容，所以我们把解释器的错误提示全部写成了学生看得懂的中文。"

## 三、评委可能追问的问题与建议回答

**Q1：和普通问答机器人有什么不同？**
A：普通机器人只有一层"通用回答"。我们把教学法做进了架构：四个学段各有一套语言参数与独立教学稿；
同一问题被追问时沿五级脚手架加深；说"听不懂"会自动降级重讲；
超出课程库的问题会明确说"没有把握"，不编造答案。

**Q2：多模态是接第三方生成服务吗？**
A：不是。动画由服务端下发绘图指令、浏览器渲染成矢量 SVG；绘本插图也是代码实时绘制的。
所以在完全断网的机房里也能用——这也是"零依赖、748KB、可离线"的原因。
如果要接文生图模型，接口层已经预留（`server/lib/llm.js` 是统一网关）。

**Q3：为什么不做成小程序或 App？**
A：赛题场景是"缓解优质教育资源不均"，Web 的部署成本最低——静态托管即可，无需审核与安装。
移动端我们也做了适配（底部导航、单列布局、390px 无横向溢出）。

**Q4：数据与隐私怎么处理？**
A：所有数据只写在本机 `data/` 目录，不上传任何服务器；学情看板提供导出与重置；
接入大模型时密钥也只保存在本机 `data/config.json`。

**Q5：工程质量怎么保证？**
A：四套自动化测试：教学引擎测试、解释器 39 项测试、接口端到端 44 项测试、
以及用 Chrome DevTools 协议驱动的真实浏览器测试（9 个页面 + 客户端脚本执行 + 控制台异常监控）。
当前全部通过，0 异常，详见 `docs/测试报告.md`。

**Q6：内容依据是什么？**
A：参照《义务教育信息科技课程标准（2022 年版）》与《普通高中信息技术课程标准（2017 年版 2020 年修订）》
中人工智能相关知识范畴，并按四个学段做了教学化改写；每个知识点都标注了对应的课标表述。

**Q7：绘本的插图是 AI 生成的吗？**
A：不是，全部是代码实时绘制的矢量图（SVG）。34 个场景、零素材、零外部图片，
所以在完全断网的机房里也能用，而且画面可以跟着年级、数据变化。
如果要接文生图模型，接口层已经预留（绘本的 `art` 字段就是一个可替换的渲染出口）。

**Q8：一年级小朋友不识字怎么办？**
A：三层兜底：① 每句上方都有带声调拼音；② 点任意汉字可以单独听这个字的读音；
③ 点「读给我听」整页朗读，语速默认比高年级慢。即使完全不识字，也能靠"听 + 看图"读完一本。

**Q9：怎么保证小朋友不会读到不适合的内容？**
A：绘本内容全是预先审定的固定文本，**没有用户生成内容直接展示**；
没有外部链接、没有广告、没有社交功能。
「问 AI」的回答会先在本册的伴读问答里匹配，匹配不到才走关键词兜底，
都匹配不到时给的是"我们一起想一想，可以去问问老师"，不编造答案。
接入大模型时同样会注入"面向低龄段"的系统约束。
