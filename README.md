# 启明 AI 课堂 · K12 人工智能通识课多模态教学助手

> 赛题：**（二）多模态K12人工智能通识课教学助手对话智能体** —— 中国移动通信集团浙江有限公司
> 形态：**多页面教学站点 + 服务端教师大脑**，零依赖、可离线运行、可接入任意 OpenAI 兼容大模型

---

## 一、这是一个什么作品

一句话：**一位会看年级下菜碟的 AI 通识课老师，外加一间能把知识点讲成五种形态的内容工坊。**

它不是"套壳聊天机器人"。三条设计主线贯穿全部代码：

**1）年龄自适应是架构级的，不是提示词级的。**
课程内容为四个学段**各写了一份教学稿**（情境导入、讲解正文、生活例子、动手活动、思考问题五件套各不相同）。
同一个「机器学习」，一年级听到的是"给机器看很多例子，它自己慢慢学会"，高三听到的是
"在假设空间中寻找使经验风险最小的参数"。年级一改，讲法、题目难度、推荐路线全部跟着换。

**2）教学法被写进了代码，而不是交给模型自由发挥。**
讲课顺序固定为「先建立直觉 → 再给生活例子 → 最后才引入术语 → 结尾必留一个思考问题」；
学生反复追问同一知识点时，讲解沿「打个比方 → 举个例子 → 拆成步骤 → 讲讲原理 → 来个挑战」**逐级加深**，而不是原地重复；
说一句"听不懂"，系统会**下调一个学段**重讲。接入大模型后，这套规矩会作为系统提示词一并注入，
所以模型不会把小学一年级的课讲成大学讲座。

**3）内容与呈现分离，同一份知识能换五种形态。**
课程库是纯数据（`server/content/`），于是同一批知识点可以渲染成：
对话讲解、可交互动画、按年级改写文字的绘本、真实可运行的代码实验、游戏化练习。
新增一个知识点，五种形态**自动全部就位**。

| 关键指标 | 数值 |
| --- | --- |
| 课程体系 | **9 个领域 · 23 个知识点 · 116 道分层练习**，每个知识点含 4 个学段的独立教学稿 |
| 多模态内容 | **12 个原理动画**（服务端下发绘图指令、浏览器渲染可交互 SVG）· **5 本 AI 绘本**（文字按年级改写 + 实时绘制插图） |
| 页面 | 9 个路由：首页 / AI 课堂 / 课程地图 / 知识点详情 / 创作工坊 / 编程实践 / 练习中心 / 学情看板 / 关于 |
| 外部依赖 | **0**（无 npm 包、无 CDN、无图片字体素材；画面全部由代码生成的 SVG 构成） |
| 学段覆盖 | 小学 1 年级 → 高中 3 年级，四个学段（低年级 / 小学高年级 / 初中 / 高中） |

## 二、如何运行

### 方式一：本地服务（推荐）

```bash
node server/server.js                        # 默认 http://127.0.0.1:8090
set PORT=8091 && node server/server.js       # 换端口（Windows）
PORT=8091 node server/server.js              # 换端口（macOS / Linux）
```

浏览器打开 `http://127.0.0.1:8090` 即可。
**只需要 Node.js（v18+，用到内置 fetch），不需要 `npm install`。**

### 方式二：后台运行

```bash
# Windows（PowerShell）
Start-Process -FilePath node -ArgumentList 'server/server.js' -WindowStyle Hidden
# macOS / Linux
nohup node server/server.js > server.log 2>&1 &
```

### 环境要求

| 项目 | 说明 |
| --- | --- |
| Node.js | v18 或更高（v24 实测通过）。仅使用内置模块：`http` / `fs` / `path` / `crypto` / `fetch` |
| 浏览器 | 任意现代浏览器（Chrome / Edge / Firefox / Safari）。界面按 1440px 与 390px 两档适配 |
| 网络 | **不联网也能完整使用**。大模型为可选增强项 |
| 数据 | 学习数据写在 `data/students/*.json`，配置写在 `data/config.json`，全部留在本机 |

## 四、年龄自适应是怎么实现的

### 4.1 四学段画像（`server/content/domains.js`）

| 学段 | 年级 | 语言风格 | 句子要求 | 用词策略 | 互动方式 |
| --- | --- | --- | --- | --- | --- |
| 小学低年级 | 1–2 | 讲故事、打比方、一句话说清 | 短句，不超过 15 字 | 只用生活常见词，术语先用比喻解释 | 看图、动手、跟读、找一找 |
| 小学高年级 | 3–6 | 从生活现象出发，先说猜想再验证 | 中等长度，一段讲清一个概念 | 可用「数据、算法、模型」并当场解释 | 小组讨论、记录观察、描述规则 |
| 初中 | 7–9 | 讲清"为什么"和"怎么调" | 完整段落，可引入变量与坐标系 | 规范术语：训练、推理、特征、评估指标 | 参数实验、错误分析、数据对比 |
| 高中 | 10–12 | 系统化、数据驱动 | 学术化表达，可用公式与复杂度 | 梯度、损失函数、向量、概率分布、对齐 | 项目式学习、实验设计、伦理研讨 |

### 4.2 一次提问的处理流水线（`server/lib/tutor.js`）

```
学生输入
  │
  ├─① 意图识别（23 类）
  │     打招呼 / 问身份 / 说谢谢 / 说再见 / 要帮助 / 听不懂 / 要深入 / 要例子 / 问原因 /
  │     问方法 / 问定义 / 要对比 / 要出题 / 要绘本 / 要动画 / 要视频 / 要编程 / 要游戏 /
  │     要学习计划 / 问伦理 / 情绪低落 / 表示同意 / 表示拒绝
  │
  ├─② 知识点定位（server/content/index.js 的 search + 同义词典）
  │     标题精确匹配 > 别名与术语强信号 > 二字组覆盖率 > 特异度校正
  │     另有 24 组同义表达表，把口语映射到知识点（例："换脸视频能信吗" → AI 安全与负责任使用）
  │
  ├─③ 上下文判定
  │     判断是「追问上一话题」还是「换了个新问题」：后者才允许切换知识点，避免答非所问
  │
  └─④ 按学段 + 脚手架层级组装回答
        层级：analogy → example → steps → principle → challenge（逐次加深，不重复）
        深度：由学段 depth 1~4 决定内容取自哪一份教学稿
        收尾：必带一个思考问题；低学段补"小任务"，高学段补"知识连接 + 动手挑战"
        输出：正文 + 知识点 + 4 个可点动作 + 相关知识网络
```

### 4.3 降级重讲

识别到"听不懂 / 太复杂 / 说人话 / 没懂"等表达时：
- 把学段**下调一级**（高中→初中，初中→小学高年级，以此类推）；
- 清空该知识点的脚手架记录，让学生可以重新爬一遍台阶；
- 若已在最低学段，则改为"一句话 + 一个比喻"的极简讲法。

### 4.4 接入大模型后自适应不丢失

`server/lib/tutor.js` 的 `systemPrompt()` 会把以下内容拼成系统提示词：
学生画像（姓名、年级、已掌握知识点）、学段参数（风格/句长/用词/互动/期望长度）、教学法约束
（先直觉后术语、听不懂就降级、结尾必提问、不要编造）、以及**本次检索到的课程知识片段**。
因此模型是在"照着课程标准和学段要求"讲课，而不是自由发挥。接口失败或超时（25 秒）会自动回退本地引擎，
并在界面提示原因，课堂不中断。

## 七、设计取舍

**为什么用服务端渲染而不是纯前端单页？**
每个知识点因此都有独立、可分享、可被搜索引擎收录的网址（如 `/topic/vision-image`），
老师可以直接把链接发到班级群；课堂投屏时不依赖浏览器端 JS 执行完毕，首屏即内容。
教学编排、题目抽取、学情统计放在服务端，学生换设备就能接着学。

**为什么坚持零依赖？**
赛题面向基础教育普惠场景。零依赖意味着：拷到 U 盘就能在机房电脑跑起来，不需要联网装包，
不会被 CDN 墙掉，不会被依赖升级搞坏。代价是自己手写了模板引擎、WebSocket 测试客户端、
迷你 Python 解释器——这些都在 `server/lib` 与 `tests` 里有清晰实现。

**为什么不把一切都交给大模型？**
因为大模型不稳定、要联网、要花钱，而且会把一年级讲成研究生课。
本作品把"教学法"和"课程标准"固化在代码与内容库里，大模型只负责把话说得更自然；
不配置任何密钥时，系统依然是一套完整可用的教学产品。

**诚实优先。**
课程库覆盖不到的问题，系统会明确说"这个问题我暂时没有把握给出可靠的答案——我不想编造内容误导你"，
并给出可查的方向。这是面向未成年人的产品应有的态度。

## 八、AI 启蒙绘本模块（面向小学 1～3 年级）

绘本不是「一页图配一句话再加一道选择题」。它是一个**独立成页、也能被任何页面嵌进去**的动画绘本子系统：
**原创角色 + 完整故事 + 情绪化画面 + 轻互动 + 温柔反馈**。
访问 **`/book`** 进入绘本馆，或 **`/book/read?id=wake&grade=1`** 直接打开某一本。
完整设计说明（分页脚本表、画面描述、台词、互动、音效、组件结构、接口）见 [绘本模块设计文档](docs/绘本模块设计文档.md)。

### 8.1 三个原创主角

| 角色 | 外形 | 口头禅 | 会犯的错 |
| --- | --- | --- | --- |

### 8.5 七种互动（像玩，不像考试）

| 类型 | 玩法 | 技术 |
| --- | --- | --- |
| **点一点** | 点小AI 的头，它会眨眼 | 按钮 + 脉冲光环 |
| **拖一拖** | 把东西拖给豆豆看它认不认得 | 拖放；**触摸设备点两下也行** |
| **吹一吹** | 对着麦克风吹气，风车转起来 | Web Audio 取 RMS，超基线 45% 判定 |
| **拍一拍** | 拍手让声控灯亮起来 | 同上，RMS 突增 12% 判定 |
| **选一选** | 两个选项，选错角色歪头说「再想想看？」 | 不锁死、不变红，可以一直试 |
| **找一找** | 在画面里找出会看/会听的东西 | 绝对定位热区 |
| **说一句** | 对着麦克风说「小AI，你好」 | Web Speech API；不支持时自动切成打字 |

**反馈原则写进代码**：答对 → 星星飞出 + 角色欢呼 + 「太棒了！」；
答错 → 角色歪头 + 「没关系，我们再来一次」+ 柔和单音。
**不扣分、不红灯、全项目不出现「错误」字样。**
麦克风打不开时每一项都有「点一下也算」的兜底按钮，绝不让小朋友卡住。

### 8.6 音效与朗读

**音效全部用 Web Audio 现场合成，零音频素材**（所以断网也能用）：
`pop` 点击 · `ding` 找到线索 · `chime` 想通了 · `clap` 拍手 · `whoosh` 吹气 ·
`cheer` 欢呼 · `giggle` 角色笑 · `warm`/`heart` 温暖收尾 · `soft` **答错时的温柔提示** · `star` 星星。

**朗读**：语速按年级给（一年级 **0.82** 很慢），音调偏高（1.25）更接近儿童故事朗读，
优先选中文女声/童声；**逐字高亮**当前字符；读一页时会把旁白和角色台词连起来读；
点任意一个汉字能单独听这个字的读音。

### 8.7 低龄段的三档自适应

| 年级 | 目标页数 | 每页句数 | 单句字数 | 可用互动 | 语速 |
| --- | --- | --- | --- | --- | --- |
| 一年级 | 8 | ≤ 1 句 | ≤ 13 字 | 点、拖、吹、拍 | 0.82 |
| 二年级 | 10 | ≤ 2 句 | ≤ 15 字 | 加 选一选、找一找 | 0.92 |
| 三年级 | 12 | ≤ 3 句 | ≤ 20 字 | 加 说一句、排一排 | 1.00 |

这些上限**写在代码里并被内容校验强制执行**——某句话超了字数，`pb-engine.validate()` 直接报错。

**按表现调整**（`pb-engine.adapt()`）：

| 触发条件 | 调整 | 对孩子说的话 |
| --- | --- | --- |
| 连续答错 ≥ 2 次 | 下一本页数 −2，只保留最简单互动 | 「没关系，我们可以读一本简单一点的。你已经很努力啦！」 |
| 最近 4 次正确率 ≥ 85% | 下一本页数 +2，多一个新玩法 | 「你太厉害了！下一本我们多读两页，好不好？」 |

另外还会按**兴趣标签**（动物 / 太空 / 音乐 / 故事 / 生活 / 朋友）推荐，**已经读过的不再重复推荐**。

### 8.9 与主对话智能体的联动

- **同一份学生档案**：绘本进度写在 `data/students/<id>.json` 的 `pb` 字段，与对话记录、错题本、徽章共用一份数据。
- **对话唤醒绘本**：低龄学生说「我想看绘本」「讲个故事」，意图识别为 `story`，回答直接给出绘本馆与最贴近那本绘本的入口。
- **绘本里也能问主智能体**：伴读问答带同义归一（能听懂「它会伤心吗」＝「它会难过吗」），答不上来就诚实说「我们一起想一想」。
- **回答转绘本**：`POST /api/pb/ask` 会把回答切成适合低龄阅读的短句，并现场画一页插图返回。

### 8.11 故事逻辑与角色人设

绘本不是「AI 走到哪儿、展示到哪儿」的流水账。**每本都必须走完黄金八步**（校验强制，缺一步报错）：

| 步 | 名称 | 要求 |
| --- | --- | --- |
| 1 | 日常状态 | 角色在熟悉的环境里，有安全感，展现性格缺陷与口头禅 |
| 2 | 打破平静 | 出现一个小麻烦或小任务 |
| 3 | 第一次尝试 | 角色自信去试，失败了 |
| 4 | 情绪低谷 | 角色沮丧，得到小朋友的鼓励 |
| 5 | 学习发现 | 角色发现线索，学到新知识 |
| 6 | 第二次尝试 | 再次尝试，部分成功但又有小插曲 |
| 7 | 最终解决 | 用学到的方法成功，获得成就感 |
| 8 | 升华与互动 | 角色用自己的话总结，并邀请孩子一起练 |

**每本一个「目标 — 障碍 — 三次尝试 — 领悟」**，例如《小AI 醒来了》：

> 目标：想学会认出一只猫　障碍：刚醒来什么都不会，第一次把老虎认成了猫
> 三次尝试：凭感觉猜 → 翻遍图画书 → 重新看一遍条纹　领悟：看多了、看得够仔细，才认得准

**因果逻辑链**（74 页逐页标注，校验强制）：

> 【第 8 页】因为看得不够仔细，所以小AI 决定再试一次——结果又把老虎认成了猫

**知识点必须「做中学」**：不由旁白直接讲，而是角色在解决麻烦的过程中被迫学会。
不写「AI 能识别图像」，而写「小AI 因为认错了猫，不得不翻遍了绘本，最后发现看多了就认识了」。

**角色必须有缺陷**（不是完美的 AI 工具）：

| 角色 | 外形记忆点 | 性格缺陷 | 口头禅 | 成长弧光 |
| --- | --- | --- | --- | --- |
| 🤖 小AI | 圆滚滚有肉感、头顶呆毛顶小灯、总抱着一条小毯子 | 有点笨笨的，总把东西认错，还爱逞强 | 「让我试试看！」「哎呀，又错了……」 | 从「什么都不会」到「看多了就认识了」 |

### 8.12 画面标准（精装出版级）

**一键全局系统前缀**（`pb.GLOBAL_PREFIX`，加在所有生图指令最前面）：

> 你是一位精装儿童绘本插画师，你的每一页画面都必须达到皮克斯动画短片级别的视觉密度。禁止使用任何纯色块、扁平矢量、素材库拼凑的简陋画风。每页必须有前中后三层景深、明确的光源与阴影、角色全身互动与微表情、至少 5 个背景细节物件。画面必须像一部正在播放的动画电影的一帧，充满空气感、体积感和故事张力。任何达不到此标准的画面，均视为无效输出。

**手绘质感全部由代码生成，零图片素材**：

| 质感 | 实现 |
| --- | --- |
| 水彩扩散 | 低频湍流 + 位移滤镜，边缘自然晕开 |
| 彩铅笔触 | 高频湍流位移，边缘带颗粒与抖动 |
| 纸纹 | 整页叠加极淡纸纤维层 |
| 皮克斯光影 | 高斯模糊柔光 + 体积光柱 + 漂浮微尘 |

**三层景深**：背景柔焦（blur 3.2）→ 中景清晰 → 前景虚化（blur 5）。

**45 种环境物件 / 7 套房间**：儿童卧室 9 件、客厅 10 件、厨房餐厅 8 件、天台夜空 8 件，
另有木纹、墙面拼块、布料褶皱三层纹理，专门消灭「一块墙」。校验强制背景 ≥5 件细节。

**强制光影**：每页写死光源方向（右窗 / 左窗 / 台灯 / 月光 / 放射 / 阴天）与影子落点；
角色与道具都有落地投影、接触阴影，家具与容器还有暗部（桌底、盒内、靠墙侧影）。

**禁止呆滞站立**：9 种身体动作（踮脚 / 趴下 / 跳起 / 后退 / 伸手 / 抱头 / 转圈 / 摔倒 / 站直），
受检 74 页中「站直不动」为 **0 页**。

**验收红线自动自查**：

```
GET /api/pb/standard   →  全局前缀 + 画风关键词 + 禁止元素 + 镜头表 + 情绪配色 + 逐页红线自查
```

当前结果：**74 页受检，0 页不达标**。

### 8.12 合规与安全
